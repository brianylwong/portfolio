## 🚀 Getting Started

### Local Development

```bash
# Clone the repository
git clone https://github.com/brianylwong/portfolio.git
cd portfolio

# Open in browser
open index.html
# or simply double-click index.html
```

### Customization

Edit the following files:
- `index.html` - Content and structure
- `styles.css` - Colors, fonts, layout
- `script.js` - Interactions and animations

### Add Your Photo

1. Get a professional headshot (400x400px minimum)
2. Save as `profile-photo.jpg` in the repository root
3. In `index.html` lines 43-46, replace:
   ```html
   <div class="profile-placeholder">
       <i class="fas fa-user-circle"></i>
   </div>
   ```
   With:
   ```html
   <img src="profile-photo.jpg" alt="Brian Wong Profile Photo" class="profile-pic">
   ```

### Add Your Resume PDF

1. Create or save your resume as `Brian_Wong_Resume.pdf`
2. Place it in the repository root
3. The download button will automatically work
